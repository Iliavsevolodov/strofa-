# СТРОФА

Интерактивный mobile-first тренажёр для запоминания стихов и любых текстов.

> ПРОЧИТАЛ → ПОНЯЛ → ВСПОМНИЛ → ВОССТАНОВИЛ → РАССКАЗАЛ → ПОВТОРИЛ

## Что уже работает

- добавление любого собственного текста;
- автоматическое разбиение текста на строфы, строки и учебные блоки;
- библиотека демо-произведений общественного достояния;
- локальное сохранение текстов и прогресса;
- светлая и тёмная темы;
- режим чтения с озвучиванием через браузерный Speech Synthesis;
- исчезающий текст;
- вставка пропущенного слова;
- сбор строки из слов;
- выбор следующей строки;
- подсказки по первым буквам;
- самостоятельное воспроизведение без текста;
- mastery по строкам и выделение слабых мест;
- отдельный экран повторения;
- адаптивный интерфейс для смартфона, планшета и компьютера.

## Стек

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- localStorage

## Запуск локально

```bash
npm install
npm run dev
```

Открой `http://localhost:3000`.

## Сборка

```bash
npm run build
npm run start
```

GitHub Actions автоматически запускает production build при push и pull request.

## Архитектура

```
app/
components/
data/
features/
  home/
  library/
  texts/
  training/
lib/
types/
```

Название приложения хранится в `lib/config.ts`, поэтому бренд можно менять централизованно.
